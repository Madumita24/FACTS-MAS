## Summary

1. All 175 tests in the 11 tracked test files pass.
2. **Stop condition hit: the headline numbers do not reproduce from the cache.** The paper reports FACTS-MAS MAPE 2.243 / 5.038 / 7.020. The current cache gives **2.094 / 4.973 / 6.855**. Naive reproduces exactly (4.194 / 7.371 / 11.168 on 2,610 cells per horizon), so the evaluation set is unchanged and the system is what changed.
3. Cause found: the paper's numbers come exactly from `full_backtest_adaptive_fused_results.pkl` (2026-07-29). That run predates two agent changes (seasonal smoothing on 08-11, event magnitude removal on 08-12). The paper's ablation and weight figures come from the newer cache. **The paper mixes results from two different versions of the system.**

5. Answers to the four questions: (a) MAPE at horizon H is the average over steps 1..H. (b) Temperature is 0.05, set by hand, not swept. (c) Calibration constants are chosen once, globally, using all six folds. (d) Production uses rho_max = 0.30, not the calibrated 0.

## What surprised me and how I checked it

- **The current system scores better than the paper says, at every horizon.** A better-than-reported number gets extra scrutiny, so I checked three things. First, naive is identical, so the cells and metric are unchanged. Second, the cache agrees with today's agent code on a random sample, so the cache is not stale. Third, the committed ablation table (made independently on 09-27) gives the same 2.094 / 4.973 / 6.855. The most likely driver is the seasonal smoothing fix, which raised seasonal weight at 4 weeks (fold weights now give seasonal 0.05 to 0.64; the July run gave it about 0.00005 at fold 1, 4 weeks). That fix was tuned on fold 6's test window (F0.5), so **part of this improvement is not clean.** I have not measured how much; that is a Phase 1 task.
- I expected the paper headline to be stale but not to find the ablation and weights from a different run in the same paper. Checked by matching each paper figure to its source file.

## Things I could not determine

- Whether the seasonal-window sweep bounded its 13-week targets before 2026-01-01. The script is not in the repo.
- What data informed the "AR skill ~0.2-0.3 in the folds tested" remark behind T = 0.05. The docstring elsewhere mentions folds 1, 3 and 5 validation windows; no record of a test-window sweep exists.
- Which numbers paper Table 6 (fold-1 comparison with TimesFM and CoT, FACTS-MAS 2.156 at 4wk) is based on. Left for the mismatch list.
- The Zillow smoothing method (believed to be a trailing average; not confirmed from Zillow documentation).
